# ChronoPulse

A developer-focused scheduled job orchestrator dashboard built with React, TypeScript, and Vite.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository into Vercel. The project uses Vite defaults: build command `npm run build`, output directory `dist`, and install command `npm install`.

> The dashboard currently uses local demo state. Connect a trusted scheduler/worker API before using it to orchestrate production workloads.
